# Remotely Save HTTP

[English](./README.md) | 简体中文

这是基于 [Remotely Save](https://github.com/remotely-save/remotely-save) 开发、供个人使用的 Obsidian 插件，专注于 **WebDAV** 同步。WebDAV 地址支持 **HTTP 和 HTTPS**，也可以通过 Tailscale 访问 HTTP 服务器。支持定时和手动双向同步。

## 当前版本的功能

- 仅使用 WebDAV 作为远端服务。
- 可通过侧边栏图标、设置页的“立即同步”按钮或“开始同步”命令手动同步。
- 默认每 5 秒静默检查并合并同步，可选 15 秒、1 分钟、5 分钟或关闭；Markdown 文件使用智能冲突处理。
- 手动同步会在顶部显示无文字的紫色细进度条。打开 Obsidian 后首次自动同步也会显示；一次可见的同步成功后，自动同步继续运行，但进度条要过 30 分钟才再次显示。文件操作完成后推进进度，仅同步成功时走满；任何同步出错都会显示进度条和具体错误原因。
- 支持 WebDAV Basic / Digest 鉴权、自定义远程文件夹、Depth 请求头和自定义请求头。
- 插件清单声明支持 Obsidian 桌面端和移动端。
- 在 Markdown 列表项的文字末尾输入空格再按回车，自动创建缩进一级的子列表项。
- 可聚焦编辑一个 Markdown 标题章节，或列表节点及其子节点，暂时隐藏同一笔记里的其他内容。

这个版本不启用其他云服务及文件端到端加密，也不会同步仓库的 `.obsidian` 配置目录。首次同步或从其他同步插件切换前，请备份仓库：双向同步可能更新或删除本地及远端文件。

## 使用 BRAT 安装（包括 Obsidian 移动端）

这个插件不能在 Obsidian 社区插件商店中直接搜索安装。先安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat)，运行它的“Add a beta plugin for testing”命令，输入 `https://github.com/guangtouge82/remotely-save-http`，选择最新 Release，然后在 Obsidian 社区插件设置中启用 **Remotely Save HTTP**。

BRAT 从本仓库的 GitHub Release 附件下载 `manifest.json`、`main.js` 和 `styles.css`。仓库里的源码本身不能直接作为安装包。

## 列表子节点

编辑 Markdown 列表时，在当前项目文字末尾输入一个空格，然后按回车。例如 `- 父节点 ` 会变成：

```markdown
- 父节点
  - 子节点
```

光标会停在新建的子节点，可继续输入“子节点”。任务列表会保留复选框类型：`- [ ] 父节点 ` 会创建缩进的 `- [ ] ` 子节点；已完成的父节点也会创建未勾选的子节点。普通回车仍按 Obsidian 原有方式创建同级项目；非列表文字和有选区时不会触发此功能。编号列表也适用。

## 聚焦编辑标题或列表节点

将光标放在 Markdown 标题或列表项（包括 `- [ ]` 任务项）上，或选中它的文字，然后从编辑器右键菜单选择“聚焦当前节点”，也可以在命令面板运行“聚焦当前节点 / 退出聚焦”。标题聚焦会显示从该标题到下一个同级或更高级标题之前的内容；列表聚焦只显示该项和缩进在其下的子项。编辑仍直接保存到原笔记。点击编辑区右上角的“退出聚焦”按钮、再次运行命令，或从右键菜单退出，即可显示完整笔记，并将刚才聚焦的节点放在编辑区垂直中间。Esc 保留给 Obsidian 的 Vim 模式。聚焦状态只在当前编辑器中临时生效，不会修改 Markdown 结构。

## 从源码安装

1. 克隆本仓库，使用 Node.js 和 npm 构建：

   ```sh
   npm install
   npm run build
   ```

2. 在 Obsidian 仓库内创建 `<仓库>/.obsidian/plugins/remotely-save-http/`，将以下三个文件复制进去：

   ```text
   main.js
   manifest.json
   styles.css
   ```

   `main.js` 是构建产物，不纳入 Git。如果不打算复用旧仓库的设置和凭据，不要复制旧的 `data.json`。

3. 若仓库开启了 Obsidian“受限模式”，先允许社区插件，再启用 **Remotely Save HTTP**。如果复制文件时 Obsidian 已经打开，请重启 Obsidian 或重新加载插件。

插件 ID 是 `remotely-save-http`，安装目录必须使用这个名字。

## 配置 WebDAV

打开 **设置 → Remotely Save HTTP**，填写：

| 设置 | 填写内容 |
| --- | --- |
| 服务器地址 | 完整的 WebDAV 端点，例如 `http://your-tailnet-host:8080/dav/` 或 `https://example.com/dav/`。包含协议、所需端口和路径。 |
| 用户名和密码 | 服务器要求登录时填写 WebDAV 凭据。 |
| 文件夹名称 | 当前仓库在 WebDAV 端点下使用的文件夹。留空时默认使用 Obsidian 仓库名；设置页会预览路径。 |

插件会在需要时创建远程仓库文件夹。多台设备同步**同一个**仓库时，请使用相同的 WebDAV 端点和文件夹名称；不同仓库应使用不同文件夹。

折叠的“高级选项”包括 Basic / Digest 鉴权、Depth 请求头（默认 `1`，服务器支持时可选 `infinity`），以及自定义请求头。自定义请求头每行填写一条 `Header: value`。

1. 点击“检查连接”。检查过程可能在服务器上创建并删除临时文件，并非只读操作。
2. 检查成功后，点击“立即同步”、侧边栏图标，或从命令面板运行“开始同步”。

只有填写有效的 `http://` 或 `https://` 地址后，检查和同步按钮才可用。若检查失败，请核对端点路径、端口、凭据和服务器连通性。

## 定时合并同步

**定时合并同步**默认在 Obsidian 打开期间每 5 秒运行一次。可改为 15 秒、1 分钟、5 分钟，或关闭。每次先读取服务器文件列表，再与本地及上次同步记录比较；只有发现变化才传输文件。若 WebDAV 服务器提供 ETag，也能识别文件大小和修改时间恰好没变的远端更新。仅服务器有更新时拉取，仅本地有更新时上传，两端都修改时使用智能冲突处理。此 WebDAV 版本停用了原有的 50% 大量变更拦截，避免有效同步被中断。首次定时检查会显示顶部进度条；一次可见的同步成功后，30 分钟内的后续检查不再重复显示。出错时始终显示错误原因，不会反复弹出更新通知或闪动同步图标。已有同步任务运行时会跳过本次定时任务；WebDAV 地址有效后才会自动同步。移动端进入后台时，定时器会暂停。

以下划线 `_` 开头的新文件和文件夹也会同步；`.obsidian` 设置目录和其他以点开头的路径仍会排除。

单个文件超过 64 MiB 时会暂时跳过该文件（本地和远端都不会删除它），因为 Obsidian 的渲染进程需要把文件完整读入内存；同步数 GB 的文件可能导致应用白屏。普通笔记和较小的附件继续同步。超大文件请单独传输。

两台设备都修改了同一个 Markdown 文件时，智能冲突处理会尝试合并。同一行发生冲突时可能产生需要人工检查的冲突标记；无法合并的文件会保留副本。缩短同步间隔能减少冲突机会，但不能保证多端编辑完全无冲突。

## HTTP 与本地设置

HTTP 本身不提供 HTTPS 的传输保护，只在你信任的网络路径中使用，例如预期的 Tailscale 连接；可以使用 HTTPS 时也可以直接使用 HTTPS。通过 Tailscale 地址同步前，请确认每台设备都连接到正确的 Tailnet。

WebDAV 设置（包括凭据）保存在仓库的插件数据中，不要将该文件提交到公开仓库。此版本不会对同步文件进行端到端加密。
